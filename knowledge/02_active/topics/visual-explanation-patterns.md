# 一页式可视化解释与 ELI5

## 当前认识

面向完全陌生的受众解释复杂概念时，可以先做一个独立 HTML 页面，用一张主图、少量标签和单一流程建立第一层心智模型。目标是降低第一次理解的门槛，不是把所有细节都删掉。

## 可复用流程

1. 明确受众、前置知识和一句核心结论。
2. 选择一个最能解释因果或循环关系的视觉骨架。
3. 用大型 SVG、图标、箭头或概率条表达结构，文字只保留短标签。
4. 把不可省略的例外、风险、来源或假设放在短注中。
5. 检查事实准确性、阅读顺序、移动端、对比度、替代文本和 reduced motion。

## 适用边界

- 适用：陌生概念导入、培训开场、机制概览、汇报中的“一页讲清楚”、可交互 HTML 图解。
- 不适用：高风险建议、需要完整论证或公式推导、多个例外决定结论、最终交付必须是可编辑 PPTX 或长篇教程。
- ELI5 是表达层，不是证据层。任何简化图都要能回到可靠来源，不能用“简单易懂”遮蔽不确定性。
