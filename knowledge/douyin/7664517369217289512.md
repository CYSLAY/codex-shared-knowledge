# Apple 的设计品味，终于被做成 Skill 了

## 核心摘要

视频介绍 Emil Kowalski 的 `Skills For Design Engineers`，重点讲 `apple-design`：将 Apple WWDC 中关于流畅界面的原则转成 Web 可执行的交互约束。视频强调，AI 常见问题不是“不会写动画”，而是选错缓动、材质、阴影、可中断性和反馈方式。其中最重要的可复用原则是：交互动画要从当前屏幕状态继续，能被用户随时抓住、打断和反向。

## 完整内容时间轴

- `00:00–00:20`：介绍项目来源与定位；它不是 Apple 官方项目，而是将 WWDC 和作者在 Vercel、Linear 的设计工程经验整理为 Skill。
- `00:20–00:40`：举例 AI 容易把进入动画用成 `ease-in` 而非 `ease-out`，或用实心边框代替半透明阴影，小错误累积会使界面始终“差一点”。
- `00:40–01:00`：视频当时将仓库概括为 6 个 Skill；`apple-design` 内将及时响应、1:1 跟手、可中断、弹簧、动量、橡皮筋边界、材质、多模态反馈、无障碍、字体和设计流程等拆成模块。
- `01:00–01:20`：强调动画不应只是从头播到尾；应从当前屏幕值继续，可打断和反向。画面展示 Pointer Events、CSS、`requestAnimationFrame`、Motion/Framer Motion 等 Web 实现对应。
- `01:20–01:40`：其他 Skill 负责动效判断、动画术语、机会发现、既有动效审查与改进计划，组成从判断、实现到复核的流程。
- `01:40–01:50`：画面给出当时安装命令，建议想小范围尝试时先从 `apple-design` 开始。

## 关键画面核验

- 视频以 9 页设计卡呈现，画面明确写出“17 个原则模块”和“动画必须能被抓住、打断、反向”。
- 实现层画面列出 Pointer Events、CSS + `requestAnimationFrame`、Motion/Framer Motion。

## 官方资料核验

- 官方仓库：<https://github.com/emilkowalski/skills>，官方介绍为“Skills For Designers and Engineers”。
- `apple-design/SKILL.md` 声明内容主要基于 Apple WWDC 设计分享并转换到 Web，而非 Apple 官方 Skill。
- 官方核心约束包括：按下即响应、1:1 跟手、可中断、速度继承、动量投射、对称路径、柔性边界、合成友好属性和 reduced-motion/对比度适配。
- 版本漂移：视频中说“一共 6 个 Skill”，处理日的官方 README 已列出更多模块，包括 `animate`、`pick-ui-library`、`prototype`、`ask-sonner` 等；以任务当时的官方 `SKILL.md` 为准，不固化“6 个”。
- 适用：手势驱动 UI、抽屉或底部面板、拖拽、弹簧、中途反向、动效审查和动画机会筛选。
- 不适用：不需要动态的纯文档页、为了“像 Apple”堆叠玻璃与弹簧，或在业务数据密集界面中使用影响读取的大幅动效。
- 来源环境状态（2026-08-20 处理时）：尚未安装该仓库 Skills；已读取 README 和 `apple-design/SKILL.md`。接收者必须在自己的环境中重新检查安装状态和当前版本。
