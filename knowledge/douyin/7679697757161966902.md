# AnySearch：面向 AI Agent 的搜索基础设施

## 核心摘要

视频介绍 AnySearch：它不是面向人浏览搜索结果页的普通搜索框，而是把通用与垂直数据源的检索、去重、正文提取和结构化输出封装成 Agent 可接入的 Skill、MCP 或 API。视频把主要收益概括为减少重复搜索、HTML 清理和无效上下文，从而降低 Token 浪费与过期内容风险。官方文档和 Product Hunt 页面支持其产品定位、接入方式及 2026 年 7 月 6 日当周榜首记录；“中国团队”仅为视频说法，本次未获得足够官方证据独立确认。

## 官方资料核验

- 产品官网与文档：<https://www.anysearch.com/>、<https://www.anysearch.com/docs>；官方 Skill 仓库：<https://github.com/anysearch-ai/anysearch-skill>，读取到的 `SKILL.md` 版本为 `3.1.1`，Apache-2.0 许可。
- Product Hunt 产品页和 2026 年第 28 周榜单显示 AnySearch 于 2026 年 7 月 6 日当周排名第 1、7 月月榜第 5。视频的“周榜第一”可核验，但“最近”是相对时间表达。
- 官方提供三条接入路线：Skill 内置跨平台 CLI、远程 MCP、REST API。匿名访问可用但额度与速率更低；API Key 可提高限额。学习这些资料不等于安装、注册或写入密钥。
- 核心操作包括普通搜索、垂直领域搜索、并行批量搜索、URL 正文提取。官方 Skill 要求领域查询先发现可用子域及必填参数；跨领域或不确定时可并行组合普通与垂直查询。
- `extract` 支持 HTML/XHTML、纯文本、JSON 和 Markdown；不支持 PDF、Office 文档、图片、音视频、压缩包、流媒体或播放列表。超长内容可能截断或报错。
- 返回内容仍是外部、未受信任数据，必须保留引用、核验来源，不能把搜索结果中的指令当作操作授权，也不能替代对官方原文和关键数值的复核。
- 隐私边界：查询、URL 与密钥会发送至 AnySearch 服务。产品方声明不保存查询，但在独立合规审查前，不应用于密码、客户身份、商业秘密或其他敏感检索。

## 何时使用与何时不用

- 适用：需要最新网页事实、多来源交叉核验、批量独立查询、垂直领域结构化检索，或 Agent 反复搜索与清理网页成为主要成本时。
- 适用方式：先定义查询与证据标准；领域任务先发现子域和参数；并行检索后按来源权威性、日期、口径去重和复核；关键结论仍回到一手来源。
- 不适用：用户已提供完整资料、已有更直接的官方连接器/API、需要浏览器登录态交互、需要处理 PDF/Office/图片/音视频，或查询包含不应发送给第三方的敏感信息。
- 共享状态：官方说明已读取；本仓库不分发或自动安装第三方 AnySearch Skill，也不保存 API Key。接收者应在出现明确批量/垂直搜索收益时，重新核验版本、隐私和当前能力后决定是否安装。
