这是一条 6 张图片组成的抖音图文笔记，不是视频。作者分享了一段名为 `eli5` 的 Skill 草案：用户输入 `/eli5` 或 `eli5 + 主题` 后，输出独立可打开的 HTML 页面，用大型 SVG/图表、极少文字和简单流程向完全不了解主题的人解释其运作方式。示例包括“大模型如何逐字生成对话”和“AI Agent 的观察—思考—行动循环”。这一方法适合建立第一层认知，但“简单”不能以牺牲正确性、重要例外、来源与可访问性为代价。

## 笔记中的 Skill 草案（结构化转述）

- `name`: `eli5`
- `description`: 当用户输入 `/eli5`、`eli5 + 主题`，或要求用最简单图解解释某事如何工作时使用。
- 输出：独立、可直接打开的 HTML 页面，不用普通聊天文本作为最终交付。
- 表达原则：大图或大型 SVG、极少文字、短标签、完整的一屏结构；用视觉关系表达结构，避免长段落。

## 何时使用与何时不用

- 适用：首次解释陌生概念、培训开场、汇报中的机制概览、需要一页 HTML 图解的主题。
- 使用方法：先定义受众和一句核心结论；只画一个主流程；对不可省略的例外、数字或风险增加短注；最后检查事实、阅读顺序、移动端和无障碍。
- 不适用：法律、医疗、金融等高风险结论需要完整依据；主题包含多重条件和反例，压缩后会误导；用户需要技术实现细节、证明过程或可编辑 PPTX 而非 HTML。
