## Skill / 工具核验

- 官方仓库：https://github.com/greensock/gsap-skills
- 官方文档：https://gsap.com/docs/v3/GSAP/
- 仓库提供多个独立 Skill：`gsap-core`、`gsap-timeline`、`gsap-scrolltrigger`、`gsap-plugins`、`gsap-utils`、`gsap-react`、`gsap-performance`、`gsap-frameworks`。
- 适用：React/Vue/Svelte/原生 JavaScript 中的时间线动画、滚动驱动动画、插件能力、框架清理与性能优化。
- 不适用：项目已经明确选择另一动画库时不应强行替换；只需要简单 CSS 过渡时也未必值得引入完整 GSAP。
- 来源环境状态：官方仓库已核验，但未安装 GSAP Skills。接收者应检查自身环境；相关任务可应用已记录的原则，只有安装后才能声称实际调用 Skill。
